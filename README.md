# Ashkanda weds Rohit — Wedding Invitation

A digital wedding invitation from the bride's family, Smt. Sangita Sharma & Sh. Ram Chand Sharma, for the wedding of their daughter **Ashkanda Sharma** with **Rohit Jadon** (son of Smt. Anita Devi & Sh. Ajay Pal Singh).

- **23 February 2027** — Ganesh Pooja, Mama Swagat, Mehndi and Haldi at our residence
- **24 February 2027** — Wedding at Sunrise Farm, NH 5, VPO, Chandigarh Rd, Jandiali, Ludhiana, Punjab 141123

## What's on the page

1. Opening doors with Lord Ganesha and an "Open Invitation" button
2. The invitation card: Ganesh mantra in Hindi, parents' invitation, couple's names and date
3. Save-the-date with an illustrated couple, live countdown and "Add to calendar"
4. Wedding festivities, grouped by day
5. Venue details with an embedded Google Map and directions
6. The families
7. Closing blessing from the Sharma family

## Tech

TanStack Start (React 19), Tailwind CSS 4, Netlify Image CDN for the illustrations, and Google Fonts (Cinzel, Cormorant Garamond, Great Vibes, Tiro Devanagari Hindi).

## Editing the details

All names, dates, venues, the mantra and event descriptions live in `src/lib/wedding.ts`.

## Running locally

```bash
pnpm install
netlify dev
```
